# Bien vivre en France

Un guide pratique pour des personnes immigrées vivant en France

## Build

- `quarto render` — render the site to `_site/`
- `quarto preview` — local dev server with live reload

## Deployment

Pushed to `main`, CI renders this project and publishes it at
<https://rondemy.ronzz.org/vie-en-france/> (see the root README).
